# DotML - Visual Machine Learning Particle Cosmos 🌌

An interactive visual universe where machine learning algorithms are explained through living data dots, animated decision boundaries, and real-time mathematical simulations. Built to make AI intuition accessible to everyone.

## ✨ Features
* **12 Interactive Algorithms:** Includes K-Means, K-Nearest Neighbors, SVM, Neural Networks, PCA, Decision Trees, and more—all mathematically implemented from scratch in TypeScript.
* **Real-Time Telemetry:** Watch loss valleys (MSE), R² scores, and Voronoi cells dynamically recalculate as you drag data dots around the canvas.
* **AI Smart Ingestion:** Powered by Gemini 3.8 Flash. Paste messy data, logs, or plain text, and the AI automatically normalizes it into a 2D coordinate space for instant ML testing.
* **Dual Arena:** Pit two different algorithms (e.g., SVM vs. KNN) against each other side-by-side on identical datasets.
